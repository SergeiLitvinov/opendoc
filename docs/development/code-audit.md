# Проверка стандартов — 2026-10-02

Проверены все производственные модули, инструменты, примеры и тесты. Для библиотеки заданы явные правила `E, F, I, N, W, BLE, ANN`; проверка форматирования включена в CI. Допустимый динамический JSON/XML объясняет исключение `ANN401`; тестовые и инструментальные функции не объявлены типизированным публичным API.

Исправлены отсутствовавшие аннотации проверок формул и выделения, длинная строка навигатора и форматирование. Импорт пакета, сборка, схемы свойств и JSON используют самостоятельное имя `opendoc`. Архитектурный тест допускает только стандартную библиотеку, внутренние модули и optional XML-бэкенд. Старые сборки и окружения удалены перед независимой установкой нового пакета.

Дальнейшие изменения проверяются по [стандартам](../../CODING_STANDARDS.md). Типы входа/выхода и лимиты не изменены ради стиля. Сложные алгоритмы сравнения и большие модули сохранены в текущем объёме; проверка lint не объявляется доказательством полной типовой или функциональной корректности.

Приёмка: 53 теста, lint с аннотациями производственного API, проверка форматирования, независимые справочники и строгая сборка сайта. Проверка имени охватывает каталоги, исходники, окружение и собранные архивы.
