# Аудиты OpenDoc Model

## Проверка устойчивости 0.3.1

Дата: 7 октября 2026. Сквозные сценарии в
[test_workflows.py](../../tests/test_workflows.py) проверяют совместную работу
существующих операций:

- отчёт с двухуровневой таблицей, внутренней ссылкой на другой раздел,
  встроенным изображением и наследуемым стилем проходит JSON, извлечение
  с замыканием зависимостей и объединение с переименованием конфликтующих ID;
- правка текста внутри таблицы сохраняет диапазон, ссылки и байты ресурса;
  проверены кириллица, иероглифы, комбинируемый знак, emoji с ZWJ и удаление;
- попытки обойти правку отслеживаемого текста или удалить его узел отклоняются
  без изменения исходника;
- внешние байты остаются неизвестными при JSON, извлечении и сравнении;
  операции не открывают источник;
- документ из 2048 абзацев проходит JSON и преобразование текста; недостаточный
  бюджет числа значений даёт явный отказ и сохраняет исходный документ.

Это синтетические модели с заданным ожидаемым результатом, а не проверка
импорта офисных файлов или визуального представления. В этих сценариях дефекты
производственного кода не обнаружены. Новые API и зависимости не добавлены;
JSON v1/v2 и сохранённый контракт API проверяются существующей регрессией.
Unicode-смещения остаются индексами кодовых точек Python: комбинируемый знак
и последовательность ZWJ могут занимать несколько позиций.

## Аудит выпуска 0.2.0

Дата проверки: 4 октября 2026. Область: код библиотеки, публичные контракты,
сохранённые схемы, состав зависимостей, лицензионные уведомления, документация,
исходный архив и wheel. Версия 0.2.0 является совместимым расширением
структур и операций над ними; назначение библиотеки сохранено.

## Исправленные ошибки

| Проверка | Проблема и исправление |
| --- | --- |
| Числа ячеек | Целое число преобразовывалось в float и могло потерять точность. SheetCell теперь различает int/float/bool, JSON сохраняет большое целое точно |
| Отчёт сохранения | Отдельный preservation_result не проверял дубли признаков и причины несемантического состояния. Он использует ту же проверку полноты и согласованности, что и документ |
| Миграции свойств | Проверка схемы использовала metadata даже для схемы properties. Введён явный scope и проверка правильного носителя |
| Медиа и visual fallback | Существующий ID мог указывать на ресурс неправильного рода. Маски/poster/visual требуют изображение; audio/video требуют соответствующий media type |

Регрессии входят в [test_integration.py](../../tests/test_integration.py).
Ошибки и исчерпание бюджета оставляют предыдущий документ/extension bag целым.
Исходные spans остаются привязанными к исходному снимку; редактирование диапазонов
выполняется отдельной операцией с явными границами и affinity.

## Границы назначения

Расширенная модель хранит сведения о полях, комментариях, ревизиях, сценах,
диаграммах, доступности, медиа, книгах и математических деревьях. Это структуры
в памяти, JSON и проверки. Она не вычисляет поля/формулы, не исполняет actions,
не отрисовывает файлы и не включает редактор, сеть, OCR или внешние движки.
Сохранение исходных bytes или визуальной замены не приравнивается к сохранению
редактируемой семантики. Профили — конечные заявления потребителя, а не обещание
поддержки полного файлового стандарта.

## Документация и лицензии

Убраны упоминания других прикладных проектов, их планы и названия задач.
Документы описывают только API OpenDoc Model, его поддержку, выпуск и зависимости.
Руководство содержит исполняемые примеры, справочники генерируются из исходников;
проверяются ссылки, якоря и строгая сборка сайта. Уточнена установка 0.2.0,
область миграций и сохранение целых чисел.

MIT-лицензия OpenDoc Model сохранена. Обязательных внешних runtime-зависимостей нет.
При аудите 0.2.0 все **35** Python-пакетов из объединения lockfile и build requirement были перечислены
в [документации зависимостей](dependencies.md), включая транзитивные, их роли,
основные лицензии и хеши исходных уведомлений. Проверка состава добавлена в CI.

Из сайта исключены неиспользуемые vendor CSS/JS и Font Awesome fonts. Для поиска
сохранены неизменённые исходники и опубликованы полные BSD/MIT/MPL-1.1-уведомления.
Проверка публикации контролирует наличие лицензий, равенство исходников поиска
установленному MkDocs и отсутствие лишних шрифтов.

У optional lxml отдельно отмечены native-компоненты и unlicensed isoschematron
resources из upstream LICENSES.txt. Сторонние компоненты не входят в wheel
OpenDoc Model; его math-код использует XML backend, но не эти isoschematron resources.
Весь lxml wheel не объявляется исключительно MIT или безусловно чистым.
Репакованное окружение проверяется отдельно.

## Приёмка выпуска

Локальная приёмка включает Ruff, форматирование, strict mypy, весь pytest,
проверку зависимостей и сайта, сборку wheel/sdist и сравнение их содержимого,
повторную сборку из sdist, независимую установку без зависимостей, публичный
typed consumer и ветви optional math. Сохранённые контракты API и JSON 0.1.0
не переписаны для обхода проверки совместимости.

GitHub release workflow повторяет проверки на Python 3.11/3.12/3.13 перед
публикацией. Затем атомарно записывает проверенную версию/тег, публикует wheel,
sdist и SHA256SUMS, обновляет сайт Pages. Предыдущий выпуск не перезаписывается.
Исходный архив не включает окружения, кэши или временные рабочие файлы.
