# Сборка и проверка выпуска

Версия пакета задаётся только литералом `opendoc.__version__` в
`src/opendoc/__init__.py`. Setuptools читает этот атрибут через dynamic version;
отдельного номера в `pyproject.toml` нет. Версия пакета не меняет версии JSON.
Build backend зафиксирован как `setuptools==84.0.0`; обновление инструмента
сборки требует повторного прогона архивных и установочных проверок.

## Проверяемые артефакты

```text
uv sync --all-extras
uv run ruff check
uv run ruff format --check
uv run pytest
uv run mypy
uv run python -m tools.docs generate
uv run python -m tools.docs check
uv build --out-dir .opendoc/release-dist
uv build --wheel <sdist.tar.gz> --out-dir .opendoc/sdist-dist
uv run python -m tools.check_distribution --dist .opendoc/release-dist --rebuilt .opendoc/sdist-dist
```

Повторная сборка получает только архив sdist; исходники проекта не передаются
build backend. `tools.check_distribution` сравнивает распакованные файлы wheel,
включая metadata/RECORD, и содержимое пакета в sdist. Это проверка одинакового
payload; временные метки ZIP не являются обещанием побитно одинаковых архивов.
Проверяются название, номер версии, Python 3.11+, отсутствие обязательных
сторонних зависимостей, заявленные extras, лицензия и `py.typed`.

Wheel содержит только `opendoc` и metadata дистрибутива. Sdist дополнительно
содержит библиотечные исходники, тесты, примеры, документацию и инструменты.
Архивы отклоняются при наличии окружений, кэшей, файлов прикладного пакета,
небезопасных путей, дубликатов или подменённой лицензии/версии.

## Установка без checkout

Каждый wheel — исходной сборки и повторной сборки sdist — устанавливается
без зависимостей в собственное пустое окружение. Затем запускаются
`tools.check_wheel` и `tools.check_types` с Python этой установки. Процессы
работают во временных каталогах с `-I`; исходники checkout исключены из импортов,
а runtime-версия обязана совпадать с metadata установленного дистрибутива.
Сценарии проверяют модель, изменение, JSON, сравнение, свойства, ресурсы,
композицию, семантические роли и статическую типизацию публичного API.

Отдельная установка с extra `math` проверяет только заявленную возможность
XML; [проверка optional backend](formulas.md#независимость-установки) описывает
парные сценарии. CI повторяет сборку и установки на Python 3.11/3.12/3.13.
Настроенный CI и локальная проверка отличаются от результата удалённого запуска.

Изменения поведения перечислены в [заметках рабочей версии](changes.md).
Эти команды создают и проверяют артефакты локально. Публикация в реестр
выполняется отдельным явно запрошенным действием.
